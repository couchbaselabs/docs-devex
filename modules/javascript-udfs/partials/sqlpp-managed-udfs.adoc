=== {sqlpp} Managed User-Defined Functions

[.status]#Couchbase Server 7.6#

For clusters using Couchbase Server 7.6 and later, you can create the code for a JavaScript function and the corresponding {sqlpp} user-defined function in a single operation in the Query Tab or cbq.
You do not have to create a UDF library before creating a {sqlpp} user-defined function.

With a {sqlpp} managed user-defined function, the JavaScript function code is stored inline, along with the {sqlpp} user-defined function.
You cannot share this JavaScript function code with other user-defined functions, or access it from a UDF library.
