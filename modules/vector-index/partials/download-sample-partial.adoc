
You can download a sample dataset to use with the procedure or examples on this page: 

https://cbc-remote-execution-examples-prod.s3.amazonaws.com/color_data_2vectors.zip[Download color_data_2vectors.zip]

For the sparse vector index examples, you must also download the sample files xref:vector-index:attachment$rgb-sparse.json[rgb-sparse.json] and xref:vector-index:attachment$vocabulary.json[vocabulary.json].

To use the sample data with the examples in this documentation, 
xref:guides:load.adoc[import the sample files] into your database with the following settings:

* Use a bucket called `vector-sample`. 
* Use a scope called `color`.
* Use the following collections:
  ** A collection called `rgb` for `rgb.json`.
  ** A collection called `rgb-questions` for `rgb_questions.json`.
  ** A collection called `rgb-sparse` for `rgb-sparse.json`.
  ** A collection called `vocabulary` for `vocabulary.json`.
* To set your document keys, use the value of the `id` field from each JSON document.
