= DROP USER
:description: The DROP USER statement enables you to delete a user.
:page-topic-type: reference
:imagesdir: ../../assets/images

:identifier: xref:n1ql-language-reference/identifiers.adoc

[abstract]
{description}

This statement permanently removes a user, revokes all their assigned roles, and removes them from all groups. 
They will no longer have access to any resources in Couchbase Server.

(Required) The username of the user you want to delete.

== Example

====
.Delete a user named Bob
[source,sqlpp]
----
DROP USER Bob;
----
