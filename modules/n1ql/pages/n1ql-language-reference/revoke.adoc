[#revoke-roles]
=== Roles
:section: roles

This syntax revokes RBAC roles from a user or group, removing a predefined set of privileges.
Roles can be global or parameterized by a keyspace.

* Global roles, such as `cluster_admin` or `bucket_admin`, apply generically to all keyspaces or resources in the cluster.
* Parameterized roles, such as `data_reader` or `query_select`, are defined for the context of the specified keyspaces only.
Use the ON clause to specified the keyspaces.

You cannot mix global and parameterized roles in the same statement, and doing so results in an error.

* `query_update` → `update`

==== TO Clause

The TO clause enables you to specify the users or groups that the statement applies to.

[source,ebnf]
----
include::partial$grammar/dcl.ebnf[tag=users-or-groups]
----

image::n1ql-language-reference/users-or-groups.png["Syntax diagram: see source code listing", align=left]

[horizontal]
user::
A user name created by the Couchbase {product-name} RBAC system.
When specifying users, the keyword `USER` or `USERS` is optional.

group::
A group name created by the Couchbase {product-name} RBAC system.
When specifying groups, you must include the keyword `GROUP` or `GROUPS`.

You can use either the singular or plural form of these keywords.
This does not affect the number of users or groups the statement applies to.

=== Credential Stores
:section: credentialstore

[.status]#Couchbase Server 8.5#
[.edition]#{enterprise}#

In Couchbase Server Enterprise Edition 8.5 and later, this syntax revokes a user or group privileges to use a specific credential from the credential store.
For more information, see xref:learn:security/credential-store.adoc[].

[source,ebnf]
----
include::partial$grammar/dcl.ebnf[tag=revoke-credentialstore-privilege]
----

image::n1ql-language-reference/revoke-credentialstore-privilege.png["Syntax diagram: see source code listing", align=left]

Currently, only one credential store privilege is available: `CONSUME CREDENTIALSTORE`.
Revoking this privilege removes the Credential Consumer RBAC role from the user or group.
For example, you can revoke a user's access to a specific AWS credential.

[horizontal]
credential:: The name of an existing credential in the credential store.

:section: catalog

[.status]#Couchbase Server 8.5#
[.edition]#{enterprise}#

In Couchbase Server 8.5 and later, this syntax revokes a user or group permission to use a specific external catalog.
For more information, see xref:learn:data/external-catalogs-and-collections.adoc[].

[source,ebnf]
----
include::partial$grammar/dcl.ebnf[tag=revoke-catalog-privilege]
----

image::n1ql-language-reference/revoke-catalog-privilege.png["Syntax diagram: see source code listing", align=left]

Currently, only one catalog privilege is available: `SELECT CATALOG`.
Revoking this privilege removes the Query External Catalog Select RBAC role from the user or group.
You need this role to run a SELECT query on an external collection which uses the specified catalog.

== Examples

.Revoke a global role
====
The following statement revokes the Cluster Admin role from multiple users.

[source,sqlpp]
----
REVOKE cluster_admin FROM david, michael, robin
----
====

.Revoke parameterized roles
====
The following statement revokes Query Select and Data Reader roles on the `travel-sample` keyspace from a specific user.

[source,sqlpp]
----
REVOKE query_select, data_reader
  ON `travel-sample`
  FROM debby
----
====

.Revoke a parameterized role from a group
====
The following statement revokes the Data Reader role on the `travel-sample` keyspace from a specific group.

[source,sqlpp]
----
REVOKE query_update
  ON `travel-sample`
  FROM GROUP sales
----
====

.Revoke a user's permission to consume a credential
====
The following statement revokes a user's permission to consume the credential `awsid`.

[source,sqlpp]
----
REVOKE CONSUME CREDENTIALSTORE ON `awsid` FROM debby;
----
====

.Revoke a group's permission to consume multiple credentials
====
The following statement revokes a group's permission to consume the credentials `awsid` and `backup_s3`.

[source,sqlpp]
----
REVOKE CONSUME CREDENTIALSTORE ON `awsid`, `backup_s3` FROM GROUP sales;
----
====

.Revoke permission to query using an external catalog
====
The following example revokes a user's Query External Catalog Select role on `sales_catalog`.

[source,sqlpp]
----
REVOKE SELECT CATALOG ON sales_catalog FROM analyst;
----
====
