== Purpose

The CREATE GROUP statement allows you to define a new group within Couchbase Server. 
The groups can have specific roles, which cont
Groups are used to organize users and manage their access control more efficiently.

After you create a group, you can assign users to it and they will inherit the roles and persmissions associated with that group.

To create a user, you can use the xref:n1ql-language-reference/createuser.adoc[CREATE USER] statement.

This statement helps manage access control and organize users within your system.

name::
(Required) The unique identifier for the new group. 

description::
(Required) A quoted string containing the name of the group.
It must be at least 6 characters long.

role::
<<roles,Roles>>

[NOTE]
====
When creating a group, you can grant roles to them using one of the following options: `ROLE`, `ROLES`, or `NO ROLES`. 
You can specify only one of these options per statement. 

* `ROLE` assigns a single role to the group.
* `ROLES` assigns multiple roles to group (the names must be separated by commas).
* `NO ROLES` creates a group with no roles assigned. 
This option has no effect during group creation. 
====

== Examples

.Create a group with the name `sales` and assign it the `query_select` role
====
[source,sqlpp]
----
CREATE GROUP sales ROLE query_select;
----
====

.Create a group with the name `agents` and assign it multiple roles
====
[source, sqlpp]
----
CREATE GROUP agents ROLES data_reader,query_select,query_insert ON `travel-sample`;
----
====
