[horizontal]
catalog::
(Required) An {identifier}[identifier] that refers to the name of the catalog that you want to create.

[[if-not-exists]]
=== IF NOT EXISTS Clause

The optional `IF NOT EXISTS` clause enables the statement to complete successfully when the specified catalog already exists.
If a catalog with the same name already exists, then:

* If this clause is not present, an error is generated.

* If this clause is present, the statement does nothing and completes without error.

[[type]]
=== TYPE Clause

Use the `TYPE` clause to specify the type of catalog.
The only supported catalog type is `ICEBERG`.

[[source]]
=== SOURCE Clause

Use the `SOURCE` clause to specify the catalog provider for this catalog.
The following catalog providers are supported.

----

The `REST` and `UNITY_CATALOG` catalog providers are synonyms.

[[at]]
=== AT Clause

Use the `AT` clause to specify the ID of the credential that Couchbase Server uses to authenticate with the catalog provider.

[horizontal]
credential::
The name of an existing credential in the credential store.
For more information about credentials and credential store, see xref:learn:security/credential-store.adoc[].

[[with]]
=== WITH Clause

Use the `WITH` clause to specify connection options for the catalog.
This clause is required.
If you do not need to specify any options, specify an empty object `{}`.

[horizontal]
options::
An object representing the options to be set for the catalog.
The options that are available depend on the catalog provider.

== Examples

.Create catalog for a REST catalog provider
====
This statement creates a collection called `city` in the `inventory` scope within the `travel-sample` bucket.

[source,sqlpp]
----
CREATE CATALOG sales_catalog TYPE ICEBERG SOURCE REST AT `query/external/iceberg-sales-catalog`
WITH { "uri": "https://iceberg-catalog.example.com" };
----
====

.Create catalog for an AWS Glue catalog provider
