== Purpose

Couchbase Server 8.5 and later supports historic queries on external collections.
If you're querying an external collection, you can use the AT clause to query the Apache Iceberg table as it was at a specific moment in time.

You can use the AT clause with a keyspace reference in any of the following locations:

* The FROM clause.
* The right-hand side of a JOIN clause.
* The right-hand side of a NEST clause.
* The right-hand side of a comma-separated join.

You can only use the AT clause on external collections, and you cannot use it inside a subquery.

For more information, see {historic-query}[Query a Snapshot in a Single Statement].

== Prerequisites

The external collection, and the external catalog that it depends on, must both exist.
For more information, see {external-catalogs-and-collections}[].

.Credentials
You must have the following credentials in the credential store:

* A credential that Couchbase {product-name} uses to communicate with the catalog provider.

* A credential that Couchbase {product-name} uses to communicate with the storage backend.

For more information, see xref:learn:security/credential-store.adoc[].

.RBAC Privileges
You must have the following roles to use a catalog and external collection:

* The Query External Catalog Select role on the catalog.
* The Credential Consumer role for the credentials used by the catalog and the external collection.
* The Query Select role on the external collection.

For more information about user roles, see
{authorization-overview}[Authorization].

[#examples]
== Examples

For the examples on this page, the path to the required keyspace is specified by the query, so you do not need to set the query context.

[#ex-at-timestamp]
.At timestamp
====
The following example queries the `orders` external collection as it existed at midnight UTC on June 1, 2026:

[source,sqlpp]
----
SELECT o.*
FROM `travel-sample`.external.orders AS o
  AT TIMESTAMP "2026-06-01T00:00:00Z";
----
====

[#ex-at-snapshot]
.At snapshot with join
====
The following example joins the `orders` collection at a specific snapshot ID with the `shipments` collection at a specific point in time:

[source,sqlpp]
----
SELECT o.*, s.status
FROM `travel-sample`.external.orders AS o
  AT SNAPSHOT 5688794825202065870
JOIN `travel-sample`.external.shipments AS s
  AT TIMESTAMP "2026-06-01T00:00:00Z"
ON o.order_id = s.order_id;
----
====
