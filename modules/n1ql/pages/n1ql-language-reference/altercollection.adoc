[abstract]
{description}

ALTER COLLECTION only enables you to alter the options for an external collection.
You cannot alter the options for a non-external collection.

include::createexternalcollection.adoc[tag=validation]

== Prerequisites

.RBAC Privileges
To execute the ALTER COLLECTION statement, clients must have the Bucket Admin or Manage Scopes role on the bucket, or any Administrative role that gives permission to add, edit, and drop scopes and collections in the bucket.
For more information, see {authorization-overview}[Authorization].

[horizontal]
namespace::
(Optional) An {identifier}[identifier] that refers to the {logical-hierarchy}[namespace] of the bucket which contains the collection you want to alter.
Currently, only the `default` namespace is available.
If the namespace name is omitted, the default namespace in the current session is used.

bucket::
(Optional) An {identifier}[identifier] that refers to the bucket which contains the collection you want to alter.

scope::
(Optional) An {identifier}[identifier] that refers to the scope which contains the collection you want to alter.

collection::
(Required) An {identifier}[identifier] that refers to the name of the collection that you want to alter.
See {naming-for-scopes-and-collections}[Naming for Scopes and Collections] for restrictions on collection names.

NOTE: If there is a hyphen (-) inside the bucket name, the scope name, or the collection name, you must wrap that part of the path in backticks ({backtick} {backtick}).
For example, `default:{backtick}travel-sample{backtick}` indicates the `travel-sample` keyspace in the `default` namespace.

[[location]]
=== Specifying the Location

To specify the location of the collection, you may do one of the following:

* Include its *((full path))*, containing the namespace, bucket, and scope, followed by the collection name;
* Include a *((relative path))*, containing just the bucket and scope, followed by the connection name;
* Specify just the collection name without a path.

When you specify a collection name without a path, you must set the {query-context}[query context] to indicate the required namespace, bucket, and scope.
If you specify a collection name by itself without setting a valid query context, an error is generated.

[[with]]
=== WITH Clause

Use the `WITH` clause to specify options for the collection.

[horizontal]
options::
An object representing the options to be set for the collection.

include::createexternalcollection.adoc[tag=collection-options]

== Examples

.Alter collection with full path
====
The following example enables the `decimal-to-double` setting a collection called `orders` in the `_default` scope within the `sales` bucket.

[source,sqlpp]
----
ALTER COLLECTION sales._default.orders
WITH { "decimal-to-double": true };
----
====

.Alter collection with query context
====
For this example, set the query context to a scope called `external` in the travel sample dataset.
For more information, see xref:n1ql:n1ql-intro/queriesandresults.adoc#query-context[Query Context].

Assuming that the query context is set, this example updates the external collection called `flights` in a scope called `external` within the `travel-sample` bucket.

The statement pins the `flights` external collection to the snapshot that was current at midnight UTC on June 1, 2026, and sets `parallelScans` to `4`.

[source,sqlpp]
----
ALTER COLLECTION flights
WITH { "snapshotTimestamp": "2026-06-01T00:00:00Z",
       "parallelScans": 4 };
----
====
