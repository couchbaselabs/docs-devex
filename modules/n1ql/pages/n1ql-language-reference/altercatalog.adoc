[abstract]
{description}

You can change any of an external catalog's provider-specific connection parameters.
However, you cannot change a catalog's name, type, or source after you create it.
If you want to change any of these values, you must create a new catalog and drop the old one.

Catalogs are global: they're not restricted to any particular scope or collection in the Couchbase {logical-hierarchy}[logical hierarchy].
The ALTER CATALOG statement is not affected by the current query context.

include::createcatalog.adoc[tag=validation]

== Prerequisites

.RBAC Privileges
To execute the ALTER CATALOG statement, clients must have the External Catalog Admin role, or any Administrative role that gives permission to create, read, update, and delete external catalogs.
For more information, see {authorization-overview}[Authorization].

== Example

[[ex-alter-catalog]]
.Alter a catalog
====
The following example changes the warehouse location for `sales_catalog`.

[source,sqlpp]
----
ALTER CATALOG sales_catalog WITH
      { "warehouse": "s3://sales-bucket/warehouse2" };
----
====
