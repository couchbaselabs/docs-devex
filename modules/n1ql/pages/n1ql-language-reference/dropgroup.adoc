= DROP GROUP
:description: The DROP GROUP statement enables you to delete a group.
:page-topic-type: reference
:imagesdir: ../../assets/images

:identifier: xref:n1ql-language-reference/identifiers.adoc

[abstract]
{description}

When deleting a group, the users associated with the group are not deleted, but they are no longer associated with the group and lose the roles and privileges granted to the group. 
If you want to delete a user, use the DROP USER statement.
