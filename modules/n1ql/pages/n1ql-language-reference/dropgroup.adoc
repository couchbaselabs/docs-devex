= DROP GROUP
:description: The DROP GROUP statement enables you to delete a group.
:page-topic-type: reference
:imagesdir: ../../assets/images

[abstract]
{description}

Deleting a group removes all roles and privileges associated with that group.
Users in the group no longer inherit the roles granted to the group.

You can use this statement to clean up groups that are no longer needed.

----
include::partial$grammar/ddl.ebnf[tag=drop-group]

image::n1ql-language-reference/drop-group.png["Syntax diagram: refer to source code listing", align=left]

[horizontal]
groupname::
(Required) The name of the group you want to delete. 

== Example

====
.Delete a group names `sales`
[source,sqlpp]
----
DROP GROUP sales;
----
