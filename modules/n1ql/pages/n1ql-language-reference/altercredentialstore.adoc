== Purpose

The `ALTER CREDENTIALSTORE` statement updates an existing named credential in the credential store.

The credential store securely holds the credentials that Couchbase services and users use to authenticate with external systems, such as AWS S3, REST APIs, or another Couchbase instance.
For more information about the credential store, see xref:<link>.
// TODO: Link to the credential store documentation.

You can use `ALTER CREDENTIALSTORE` to:

* Rotate authentication secrets
* Change the expiration date
* Update the description
* Modify the guardrails applied to a credential

To update a credential, provide the name of an existing credential and a `WITH` clause containing the new definition of the credential.
The `WITH` clause fully replaces the credential's existing definition. 
Any omitted field is cleared or reset to its default value rather than retained from the previous definition. 

When you do, include every field that the credential should have after the update, not only the fields that changed.

== Prerequisites

Before you run the `ALTER CREDENTIALSTORE` statement:

* You must enable credential store, and the named credential must exist in it. 
For more information, see xref:<link>.

=== WITH Clause

The `WITH` clause accepts a JSON object containing the new definition of the credential.
Because the provided object completely overwrites the existing definition, include all required and optional fields for the updated credential. 

[cols="1,2,1", options="header"]
|====
| Name | Description | Schema

| **type** +
__required__

a| The type of external system the credential authenticates with.

Supported values include:

* `couchbase`
* `aws`
* `awsInstanceMetadata`
* `azureShared`
* `azureAd`
* `azureSas`
* `azureManaged`
* `gcp`
* `gcpAdc`
* `http`

Several of these values cover more than one credential variant, and the variant is determined by the fields you supply.
The required structure of the `fields` object depend on the specified `type`.
For more information, see <<fields>>.

| String

| **fields** +
__required__

| The authentication parameters corresponding to the specified `type`.

| <<fields>> object

| **description** +
__optional__

| A description of the credential.

| String

| **expiresAt** +
__optional__

| An expiration timestamp in epoch milliseconds.
The timestamp must be set to at least 5 minutes in the future.
After this time passes, requests that use the credential fail with an error.

| Number

| **guardrails** +
__optional__

| Access control policies that restrict where and how the credential can be used.
For example, limiting usage to specific services or URLs.

| <<guardrails>> object
|====

=== Fields

The required and optional parameters within the `fields` object depend on the value specified for `type`.

[cols="2,1,3,3", options="header"]
|===
| Credential Type | `type` Value | Required Fields | Optional Fields

| Couchbase Server or Capella (Basic + TLS)
| `couchbase`
| `username`, `password`, `encryptionType`
| `rootCertificate`

| Couchbase Server or Capella (mutual TLS)
| `couchbase`
| `certificate`, `privateKey`, `encryptionType` (`full`)
| `passphrase`, `rootCertificate`

| AWS S3
| `aws`
| `accessKeyId`, `secretAccessKey`, `region`
| `sessionToken`, `endpoint`

| AWS S3 (EC2 instance metadata)
| `awsInstanceMetadata`
| `region`
| `endpoint`

| Azure Storage (shared key)
| `azureShared`
| `accountName`, `accountKey`
| `endpoint`

| Azure (client secret)
| `azureAd`
| `clientId`, `clientSecret`, `tenantId`
| `endpoint`

| Azure (client certificate)
| `azureAd`
| `clientId`, `certificate`, `tenantId`
| `certPassword`, `endpoint`

| Azure (SAS token)
| `azureSas`
| `accountName`, `sharedAccessSignature`
| `endpoint`

| Azure (managed identity)
| `azureManaged`
| `managedIdentityId`
| `endpoint`

| GCP (service account)
| `gcp`
| `jsonCredentials`
| `region`, `endpoint`

| GCP (backup service)
| `gcp`
| `accessKeyId`, `secretAccessKey`
| `region`, `endpoint`

| GCP (Application Default Credentials)
| `gcpAdc`
| None
| None

| HTTP Basic authentication
| `http`
| `authScheme` (`basic`), `username`, `password`
| `rootCertificate`, `skipVerify`

| HTTP Bearer token
| `http`
| `authScheme` (`bearer`), `token`
| `headerName`, `rootCertificate`, `skipVerify`

| HTTP mutual TLS
| `http`
| `authScheme` (`mtls`), `certificate`, `privateKey`
| `passphrase`, `rootCertificate`, `skipVerify`
|===

[NOTE]
====
* Types like `awsInstanceMetadata` and `gcpAdc` authenticate using identity attached to the runtime environment.
** For `awsInstanceMetadata`, include only non-secret region or endpoint settings.
** For `gcpAdc`, pass an empty object (`{}`).

* Couchbase masks secret values (such as `secretAccessKey`, `accountKey`, or `clientSecret`) upon submission and does not return them in plain text.
====

=== Guardrails

[cols="1,2,1", options="header"]
|====

| Name | Description | Schema

| **allowedServices** +
__optional__

| A list of Couchbase services (such as `n1ql`, `backup`, `index`) permitted to use the credential.

If omitted, all services can use the credential.

| Array of strings

| **urlWhitelist** +
__optional__

| Restricts the target URLs where the credential can be applied.

| <<whitelist>> object
|====

==== Whitelist

[cols="1,2,1", options="header"]
|====

| Name | Description | Schema

| **allAccess** +
__optional__

| Set to `true` to allow all URLs.
This setting overrides `allowedUrls` and `disallowedUrls`.

| Boolean

| **allowedUrls** +
__optional__

| URL patterns where credential usage is permitted.

| Array of strings

| **disallowedUrls** +

| URL patterns where credential usage is blocked.

| Array of strings
|====

== Examples

.Update the secret access key for the credential named `awsid`
====

[source,sqlpp]
----
ALTER CREDENTIALSTORE `awsid` WITH {
    "type": "aws",
    "fields": {
        "accessKeyId": "AKIAIOSFODNN7EXAMPLE",
        "secretAccessKey": "wJalrXUtnFEMI/K7MDENG/bPxRfiCYNEWEXAMPLE",
        "region": "us-west-3"
    }
};
----
====

.Update the description and expiration date of the credential named `backup_s3`
====

[source,sqlpp]
----
ALTER CREDENTIALSTORE `backup_s3` WITH {
    "type": "aws",
    "fields": {
        "accessKeyId": "AKIAIOSFODNN7EXAMPLE",
        "secretAccessKey": "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY",
        "region": "us-west-2"
    },
    "description": "Production S3 access for backups (renewed)",
    "expiresAt": 1830297600000
};
----
====

.Update the guardrails for the credential named `backup_s3`
====

[source,sqlpp]
----
ALTER CREDENTIALSTORE `backup_s3` WITH {
    "type": "aws",
    "fields": {
        "accessKeyId": "AKIAIOSFODNN7EXAMPLE",
        "secretAccessKey": "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY",
        "region": "us-west-2"
    },
    "description": "Production S3 access for backups (renewed)",
    "expiresAt": 1830297600000,
    "guardrails": {
        "allowedServices": ["backup", "n1ql"],
        "urlWhitelist": {
            "allAccess": false,
            "allowedUrls": ["https://s3.amazonaws.com/*"]
        }
    }
};
----
====

.Rotate the secret access key for the credential named `backup_s3`
====
`ALTER CREDENTIALSTORE` always performs a full replace of the credential's definition.
To rotate the secret without losing the credential's other settings, repeat `description`, `expiresAt`, and `guardrails` alongside the new `secretAccessKey`.

[source,sqlpp]
----
ALTER CREDENTIALSTORE `backup_s3` WITH {
    "type": "aws",
    "fields": {
        "accessKeyId": "AKIAIOSFODNN7EXAMPLE",
        "secretAccessKey": "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",
        "region": "us-west-2"
    },
    "description": "Production S3 access for backups (renewed)",
    "expiresAt": 1830297600000,
    "guardrails": {
        "allowedServices": ["backup", "n1ql"],
        "urlWhitelist": {
            "allAccess": false,
            "allowedUrls": ["https://s3.amazonaws.com/*"]
        }
    }
};
----
====

[NOTE]
====
`type` is immutable.
`ALTER CREDENTIALSTORE` cannot change a credential's `type`; the value you supply must match the credential's existing `type`, or the statement fails.
To change a credential's type, drop and recreate it instead.
====
