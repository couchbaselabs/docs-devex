== Purpose

The `ALTER CREDENTIALSTORE` statement updates an existing credential in the credential store.

The credential store securely holds the credentials that Couchbase services and users use to authenticate with external systems, such as AWS S3, REST APIs, or another Couchbase instance.
// TODO: For more information about the credential store, see xref:<link>. Link to the credential store documentation.

When you use this statement, the `WITH` clause completely replaces the existing credential definition. 
To avoid losing the existing settings, specify both the changed and unchanged fields in the `WITH` clause.

You can update fields such as region, access key, or description, but you cannot change the name or type of the credential. 
The `type` value in the `WITH` clause must match the existing type of the credential. 
If you need to rename a credential or change its type, drop the credential and recreate it.

NOTE: The `ALTER CREDENTIALSTORE` statement is available only in Couchbase Server 8.5 and later.

== Examples

NOTE: Because `ALTER CREDENTIALSTORE` performs a full replace of the credential's definition, include every field you want to retain, not just the fields you're changing.

.Update the region for a credential named `awsid`
====

To create the `awsid` credential used in this example, see the examples in xref:n1ql:n1ql-language-reference/createcredentialstore.adoc#examples[CREATE CREDENTIALSTORE].

[source,sqlpp]
----
ALTER CREDENTIALSTORE `awsid` WITH {
    "type": "aws",
    "fields": {
        "accessKeyId": "AKIAIOSFODNN7EXAMPLE",
        "secretAccessKey": "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY",
        "region": "us-west-1"
    }
};
----
====

.Update the description and expiration date of a credential named `backup_s3`
====

To create the `backup_s3` credential used in this example, see the examples in xref:n1ql:n1ql-language-reference/createcredentialstore.adoc#examples[CREATE CREDENTIALSTORE].

[source,sqlpp]
----
ALTER CREDENTIALSTORE `backup_s3` WITH {
    "type": "aws",
    "fields": {
        "accessKeyId": "AKIAIOSFODNN7EXAMPLE",
        "secretAccessKey": "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY",
        "region": "us-west-2"
    },
    "description": "Production S3 access for backups (renewed)",
    "expiresAt": 1830297600000,
    "guardrails": {
        "allowedServices": ["backup"],
        "urlWhitelist": {
            "allAccess": false,
            "allowedUrls": ["https://s3.amazonaws.com/*"]
        }
    }
};
----
====
