== Purpose

The `DROP CREDENTIALSTORE` statement permanently removes an existing named credential from the credential store.

The credential store securely holds the credentials that Couchbase services and users use to authenticate with external systems, such as AWS S3, REST APIs, or another Couchbase instance.
For more information about the credential store, see xref:<link>.
// TODO: Link to the credential store documentation.

NOTE: Dropping a credential is irreversible.
Any statement or feature that references the dropped credential fails until you recreate a credential with that name.

== Prerequisites

To run the `DROP CREDENTIALSTORE` statement, you must have one of the following roles:

** Full Admin
** Credential Admin
** Security Admin

For more information about roles and privileges, see {roles}[Roles].

[[if-exists]]
=== IF EXISTS Clause

The optional `IF EXISTS` clause enables the statement to complete successfully even when the specified credential is not present in the credential store. 

* Clause present: The statement completes successfully, even when the credential does not exist. 
* Clause omitted: The statement does nothing and completes without error.

== Examples

.Drop a credential named `awsid` if it exists
====

[source,sqlpp]
----
DROP CREDENTIALSTORE IF EXISTS `awsid`;
----
====
