[[on]]
=== ON Clause

Use the `ON` clause to specify the name of the catalog on which the external collection is based.

[horizontal]
catalog::
The name of an existing catalog.

[[at]]
=== AT Clause

Use the `AT` clause to specify the ID of the credential that Couchbase Server uses to authenticate with the storage backend.

[horizontal]
credential::
The name of an existing credential in the credential store.
For more information about credentials and credential store, see xref:learn:security/credential-store.adoc[].

[[with]]
=== WITH Clause

Use the `WITH` clause to specify additional options for the collection.

[horizontal]
options::
An object representing the options to be set for the collection.

== Examples

.Create external collection
====
This statement creates an external collection that exposes the `orders` table from `sales_catalog`.

[source,sqlpp]
----
CREATE EXTERNAL COLLECTION `sales`.`_default`.`orders`
ON sales_catalog AT `query/external/iceberg-sales-table`
WITH {
  "namespace": "sales_db",
  "tableName": "orders"
};
----
====

.Create collection with query context
====
include::ROOT:partial$query-context.adoc[tag=example]

Assuming that the query context is set, this statement creates a collection called `country` in the `inventory` scope within the `travel-sample` bucket.

[source,sqlpp]
----
CREATE EXTERNAL COLLECTION `travel-sample`.`external`.`flights`
ON flights_catalog AT `query/external/iceberg-flights-table`
WITH {
  "namespace": "flight_data",
  "tableName": "flights"
};
----
====
