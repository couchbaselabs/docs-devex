Catalogs are global: they're not restricted to any particular scope or collection in the Couchbase {logical-hierarchy}[logical hierarchy].
The DROP CATALOG statement is not affected by the current query context.

include::server:manage:partial$drop-catalog-info.adoc[]

== Prerequisites

.RBAC Privileges
To execute the DROP CATALOG statement, clients must have the External Catalog Admin role, or any Administrative role that gives permission to create, read, update, and delete external catalogs.
For more information, see {authorization-overview}[Authorization].

(Required) An {identifier}[identifier] that represents the name of the catalog that you want to delete.

[[if-exists]]
=== IF EXISTS Clause

The optional `IF EXISTS` clause enables the statement to complete successfully when the specified catalog does not exist.
If a catalog with the same name does not exist, then:

* If this clause is not present, an error is generated.

* If this clause is present, the statement does nothing and completes without error.

== Examples

.Drop a catalog
====
[source,sqlpp]
----
DROP CATALOG `sales-catalog`;
----
====

.Drop a catalog if it exists
====
[source,sqlpp]
----
DROP CATALOG IF EXISTS `flight-catalog`;
----
====
