== Configure Plan Stability

You can configure plan stability using 1 of the following methods:

** <<using-the-couchbase-server-web-console>>
** <<using-the-system-settings-catalog>>
** <<using-the-prepare-statement>>

=== Using the Couchbase Server Web Console

When you configure Plan Stability in the Couchbase Server Web Console, settings apply automatically to every query node in your cluster. 

. In the Couchbase Server Web Console, go to menu:Settings[Query].

. From the *Plan Stability* list, select a mode. 
+
--
* `Off`: Does not save execution plans to disk.
* `On Prepared Statements`: Saves execution plans to disk for all prepared statements.
* `On All Statements`: Saves execution plans to disk for all queries, including prepared statements and ad-hoc queries.
* `Frozen`: Does not save execution plans to disk for new queries, but uses existing saved plans for matching queries.
--
+
For more information about these modes, see xref:n1ql:n1ql-manage/query-plan-stability.adoc#plan-stability-modes[Plan Stability Modes].

. From the *Plan Stability Error Policy* list, select an error policy. 
+
--
* `Strict`: Stops execution and returns the error to the application.
* `Moderate`: Generates a new plan to execute the statement, but keeps the original saved plan.
* `Flexible`: Generates a new plan to execute the statement and overwrites the saved plan with the new one.
--
+
For more information about these policies, see xref:n1ql:n1ql-manage/query-plan-stability.adoc#error-policies[Error Policies].

. Click btn:[Save].

=== Using the System Settings Catalog

To configure Plan Stability programmatically, run an `UPDATE` statement against the `system:settings` catalog.
These settings apply at the cluster level to every query node in your cluster.

To set the Plan Stability mode, use the following query: 

[source,sqlpp]
----
UPDATE system:settings SET plan_stability.mode = "off";
----

To set the Plan Stability error policy, use the following query: 

[source,sqlpp]
----
UPDATE system:settings SET plan_stability.error_policy = "moderate";
----

For a list of acceptable values for `plan_stability.mode` and `plan_stability.error_policy`, see xref:n1ql:n1ql-intro/sysinfo.adoc#sys-settings[Monitor Settings].

=== Using the PREPARE Statement

You can also configure Plan Stability for individual queries.
When you create a prepared statement using `PREPARE`, include the keyword `SAVE` to save the plan to persistent storage.

* With `SAVE`: Saves the execution plan to persistent storage. 
* Without `SAVE`: Keeps the execution plan in memory only. 

The following example shows how to use `SAVE`: 

[source,sqlpp]
----
PREPARE SAVE get_route_by_airline FROM
SELECT * FROM route
WHERE airline = "FL";
----

For more information, see the xref:n1ql:n1ql-language-reference/prepare.adoc[PREPARE] statement.

== View Saved Plans

To view all saved execution plans, use the `system:prepareds` catalog.

If you want to retrieve a specific saved plan from the list, use its plan name:

* For prepared statements, the plan name matches the name you specify in the `PREPARE` statement.

* For ad-hoc queries, the Query Service generates a plan name automatically from the statement text. 

To view all saved plans, use the following query:

[source,sqlpp]
----
SELECT *, meta().plan FROM system:prepareds;
----

To find the saved plan for a specific ad-hoc query, filter by the statement text:

[source,sqlpp]
----
SELECT *, meta().plan FROM system:prepareds WHERE statement LIKE "%FROM route WHERE airline%";
----

Similarly, you can also delete saved plans from `system:prepareds`.
For more information, see xref:n1ql:n1ql-manage/monitoring-n1ql-query.adoc#sys-prepared[Monitor and Manage Prepared Statements].

== View Plan Stability Settings

To get the cluster-wide Plan Stability settings, use the `system:settings` catalog.

[source,sqlpp]
----
SELECT * FROM system:settings;
----

This query returns the current `mode` and `error_policy` values, for example:

[source,json]
----
[
  {
    "settings": {
      "plan_stability": {
        "mode": "ad_hoc",
        "error_policy": "moderate"
      }
    }
  }
]
----

For more information, see xref:n1ql:n1ql-intro/sysinfo.adoc#sys-settings[Monitor Settings].
