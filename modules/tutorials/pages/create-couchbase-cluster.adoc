== Prerequisites

Before starting this tutorial, you must have a Couchbase Capella account. If you do not have one already, xref:cloud:get-started:create-account.adoc[Create an Account]. 

== Create and Deploy a Cluster

Each Capella account includes one free tier operational cluster. This tutorial uses the free tier cluster to store and manage student records. 

To create and deploy a cluster: 

. Sign in to https://cloud.couchbase.com/[Couchbase Capella]. 

. On the Operational Clusters page, click btn:[Create Cluster].

. Select *My First Project* as the project for your cluster. 

. Under *Cluster Option*, select btn:[Free].

. In the *Cluster Name* field, enter *student-cluster*.

. (Optional) Provide a description of your cluster.

. Select one of the available cloud service providers: 
* xref:reference:aws.adoc[AWS]
* xref:reference:gcp.adoc[Google Cloud]
* xref:reference:azure.adoc[Azure]

. Select an available geographic region for your cluster.

. Accept the default *CIDR Block* for your cluster.
If you wish to configure a different CIDR Block, see xref:clusters:databases.adoc#cloud-provider[Cloud Service Provider, Region, and CIDR Block]. 

. Click btn:[Create Cluster] to deploy the cluster.
